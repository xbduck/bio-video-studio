## 一、一句话命题（logline）

暴雨夜运力告急，猫老板下达「未接单超十五分钟批量取消」的团队决策；运营值守 TT虎 先一条不落地执行完，再在规则内补上「特殊乘客白名单」，让团队决策更周全——既从言行上完全支持团队，又站住了同事的承诺。

## 二、立场锚（末镜回收）

- 落点：第 2 镜 TT虎 对兔妈妈说「我帮你盯着。」
- 回收：第 12 镜末句「你答应她的，我答应你的。」

## 五、母版第 7 节自检勾选

**主题与角色**
- [x] 角色只用确认班底（TT虎 / 猫老板 / 小助手 / 兔妈妈）+ 无名客串（独居老年动物乘客，不命名），无新造常驻角色、无人类
- [x] 主题落在「说到做到」对内定义（言出必行；在团队协同中站对方角度、完全支持团队决策），通过 2.2 跑题三问，非对外服务态度
- [x] 含「对方/压力源」（兔妈妈、猫老板）与「公司侧既定对象」（批量取消决策）两个必备支点

**结构与反转**
- [x] 有 logline、立场锚（第 2 镜「我帮你盯着」），末镜（第 12 镜）原样回收
- [x] 含 3 次反转，每次有「预期/实际/逻辑来源」，来自真实职场逻辑（非巧合/事故）
- [x] 反转 3 落点是「升级成全城新规则」，不是「老板破例」

**导演工艺**
- [x] 第 1 镜前 3 秒有信息事件（大屏红色告警炸开 + 暴雨声先入），无空镜慢起
- [x] 景别有全景（1、12）/ 中景（2、3、7、10）/ 近景特写（4、5、6、8、9、11）序列，无连续 3 镜同景别同机位
- [x] 每镜情绪压进帧内小动作（爪悬停一拍、视线往返、肩背沉、耳麦、眼眶红、靠回椅背、落笔），无夸张表演
- [x] 每镜有切镜锚点（动作中切：悬停→按下；视线切：看屏→看对方；声音桥：拍桌/按键；位置匹配：灰记录→白名单点亮）；反转后留白；末镜停留 ≥2s
- [x] 光影冷暖随六拍推进（B1 蓝橙 → B2 冷 → B3 红 → B4 暖 → B5 冷/绿暖 → B6 暖金万家灯火）；BGM 走完「轻起→绷紧→留白→展开→收和弦」
- [x] 视觉母题：名单一条条变灰 → 白名单重新点亮（首尾呼应，贯穿 B3 与 B6）

**逻辑护栏**
- [x] TT虎 未开车、未越权代劳（零手动派单/转单/打电话找司机）、未递伞送客；兑现靠「系统自动派单」
- [x] 无外部事故巧合式转折；矛盾来自公司侧（批量取消决策）；无自相矛盾处理（先取消→再由白名单/新规则让系统重新保障，分属两次系统动作）
- [x] 旁白只描述画面真实存在的动作；数字写中文（一百三十七单、八十一岁、二十三单、六单），无英文缩写

**工程与声音**
- [x] 每镜 `image_prompt` 带视觉 DNA 前缀，`video_prompt` 以静态机位句开头
- [x] `year`/`age` 留空；每镜含 `sound`（环境/拟音/BGM/旁白 四层）
- [x] `duration` 合计 140s（≥120）；`aspect: landscape`；旁白 ≤4.3 字/秒
- [x] 角色外观与角色圣经一致（橙黄金虎皮、王字纹、脸颊每侧 2 条「>」虎纹、蓝工装工牌）
