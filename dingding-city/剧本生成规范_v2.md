# 剧本生成规范 · 叮叮城故事系列通用母版 v3

> **本文件是 9 集共用的剧本母版（最高约束），不含任何单集专属剧情。**
> 网页「生成剧本」按钮会把本规范路径一并放进提示词；动笔前必须先读 `角色圣经.md`（角色特征 + 视觉 DNA）、`系列总览.md`（价值观原文）与本文件。三份都不读就写，必然跑偏（v1–v6 血泪教训）。
>
> **分工**：本母版只规定「每集都成立的规则」；本集的关键词、钩子、立场锚、对方角色、视觉母题由**单集任务提示词**携带（见第 5 节清单），母版不预设剧情。
>
> **v3 相对 v2 的升级**：从 EP.02 专用稿改为 9 集通用母版——立场锚替代承诺锚、六拍弧光按三簇价值观通用化、动作白名单 / 黑名单去剧情化、补「单集提示词专属信息清单」；保留 v2.1 的时长口径（≥2 分钟）与第 3A 节导演工艺。

## 0. 栏目定位与硬规格

- **垂直类型**：企业文化虚构动物 IP 短剧，**不是生平短片、不是对外服务宣传片**。没有 `year` / `age`，不写真实人物。
- **主角**：TT虎；**城市**：叮叮城；**系列**：叮叮城故事；**规模**：共 9 集，对齐 T3 价值观表（3 大核心价值观 × 3 个行为关键词，见 `系列总览.md`）。
- **画幅**：横屏 16:9（`aspect: landscape`）。
- **成片时长：2–3 分钟（120–180 秒），不得短于 2 分钟。** 宁可加镜、放慢呼吸段，不靠拉长单镜或重复画面凑时长。
- **唯一事实来源**：`系列总览.md`（集数 ↔ 关键词 ↔ 价值观对内原文）、`角色圣经.md`（外观锁死）、本规范（通用题材 / 结构 / 导演工艺 / 护栏）、`分镜模板.md`（schema 与视觉 DNA 前缀）、`选题库.md`（每集剧情钩子）。

### 两种节奏档（开工先选一档，全集统一，不混切）

| 档位 | 镜数 | 单镜时长 | 总时长 | 适用 |
|---|---|---|---|---|
| **A · 抒情叙事档**（EP.01 定稿采用） | 12–13 镜 | 10–13 秒 | 120–160 秒 | 价值观收束、情绪沉淀、旁白驱动 |
| **B · 紧凑档**（README 第十一节产线默认） | 18–24 镜 | 5–7 秒 | 120–168 秒 | 事件密集、动作多、需要快切 |

> 每镜 `duration` 必须是整数秒；全集合计 **≥120 秒且 ≤180 秒**。选 A 档不出现 5 秒短镜，选 B 档不出现 13 秒以上长镜；B 档若合计不足 120 秒，**加镜**而不是把单镜拉长。

## 1. 确认班底（禁止新增常驻角色，按集调配）

### 1.1 常驻角色与出场规则

| 角色 | 身份（锁死） | 出场规则 | 戏路（按集可变，不固定） |
|---|---|---|---|
| **TT虎** | 叮叮城运营中心**夜班值守 / 运营管家**，坐调度台前盯大盘、执行制度、处置异常 | **每集必出** | 主角；**他不是司机，永远不出车接单**；白色小车只是通勤车 |
| **猫老板** | 城市运营负责人，灰毛 / 圆眼镜 / 灰西装 | **按需出场**：本集有决策 / 诱惑 / 分歧 / 质疑时才出 | 不是固定反派，也不是固定好人：可以是抛诱惑者（EP.01）、下决策者（EP.02）、平等对话方（EP.08）、质疑方（EP.05），按本集命题定 |
| **机器人小助手** | 轻盈飘浮、手持平板，可投红光（警示）/ 绿光（合规） | **按需出场**：需要提醒、信息显影、数据投影时才出 | 辅助，飘来、指向、投影，不抢戏、不替主角做决定 |
| **兔妈妈** | 客服中心坐席，灰白短毛、长耳直立、米色风衣 + 耳麦 | **客服口专用**：仅当本集需要客服 / 工单对手戏时复用（EP.02 起） | 承诺 / 协同的「对方」；**不要新造同类角色替代她** |

### 1.2 一次性角色与客串（不立常驻）

- **本集一次性同事 / 对手**：若命题需要班底外的同事（新人、其他部门、讨论对手），一律用动物，**不命名、不写小传、不跨集复用**，只在本集承担功能；需要客服口就优先用兔妈妈。
- **客串乘客 / 市民**：动物，**不命名、不立人设、不给台词小传**，只承担「这件事为什么重要」的由头；情绪落点可复用同色系的小兔宝。
- **铁律：叮叮城只有动物，没有人类。** 既破世界观，又与产线红线 `NO human hands` 冲突。
- ❌ 禁止新造常驻角色（如「小鹿」客服、人类同事）；❌ 禁止给一次性角色起名字、写背景故事、让他跨集出现成准常驻。

### 2.2 跑题判定三问（任一答「否」即跑题，重写）

1. 情境发生在**公司内部**（同事之间 / 部门之间 / 流程制度 / 决策 / 任务目标）吗？
2. 矛盾来自**公司侧的动作**（既定决策、制度要求、业绩诱惑、工作难题、意见分歧、目标缺口），而不是外部乘客的遭遇吗？
3. 主角的选择改变的是**内部工作结果 / 团队协作质量 / 个人职责交付**，而不是一次对外服务的好坏吗？

| ✅ 对内（合格） | ❌ 对外（跑题） |
|---|---|
| 两个部门之间的承诺与兜底 | 老人等不到车，主角陪她 / 哄她 |
| 先执行既定决策，再在规则内把决策补周全 | 乘客投诉，主角态度好地安抚 |
| 对老流程起好奇、自学后把效率提上去 | 主角冒雨送伞、亲自把乘客送到家 |
| 帮新人补位并教会对方，而不是替他做完 | 靠一次热心服务赢得乘客表扬 |

### 2.3 每集两个必备支点（通用，不绑定具体剧情）

- **支点一 · 对方 / 压力源**：本集命题的另一头——可以是猫老板（决策 / 诱惑 / 分歧）、兔妈妈或一次性同事、一个工作难题、一个被质疑的新想法。
- **支点二 · 公司侧既定对象**：一条制度、一个已下达的决策、一个团队目标、一个现状缺口。主角**先正视或先服从它，再在规则内推进自己的选择**，而不是绕开它、对抗它、另搞一套。

## 3. 编剧结构（A 档 12 镜为例；B 档按比例拆分事件，弧光不变）

### 3.1 先写命题，再写镜头

开工先交三行文本，通过后才进分镜：

1. **一句话命题（logline）**：主角 + 立场 / 目标 + 阻碍 + 兑现方式，一句说完。
2. **立场锚**：第 2 镜前后落下一句可复述的立场台词或一个标志性动作，**末镜必须原样或变奏回收**。形态随簇变化：
   - 可信簇：承诺句（EP.02「我帮你盯着」）、初心闪回（EP.01 手册第一页）、担责表态（EP.03）；
   - 有用簇：一句好奇自问、一个改善念头、一个可验收目标；
   - 共生簇：一句带教约定、一句平等共识、一句顾全大局的表态。
3. **反转表**（见 3.3）。

### 3.2 通用六拍与镜数配比（A 档 12 镜）

| 拍 | 镜位 | 职责 | 内容（按本集命题填充，不绑定具体事件） |
|---|---|---|---|
| B1 日常 / 立场建立 | 镜 1–2 | 立情境、落立场锚 | 日常运营 / 工作现场，主角亮出本集立场（承诺、初心、好奇、带教约定、共识） |
| B2 压力落下 | 镜 3 | 压力来源 | 公司侧的决策 / 诱惑 / 难题 / 分歧 / 缺口落到主角面前 |
| B3 选择 / 第一反应 | 镜 4–5 | 反转 1 | 观众预期的捷径、回避、迎合出现，主角做出与价值观一致的选择（先执行 / 先担起 / 先钻研 / 先补位） |
| B4 深化 / 看见 | 镜 6 | 反转 2 | 换到对方角度、看见盲区、发现老问题、被质疑后沉下去 |
| B5 坚持 / 证明 | 镜 7–9 | 悬崖 + 证明 | 提出建议 / 新思路 / 补位 → 被拒或被质疑 → 用数据、事实、行动再证明，全程不越权、不拍桌、不替别人做完 |
| B6 兑现 + 升级 + 点题 | 镜 10–12 | 反转 3 + 回收 | 结果落地（系统自动完成 / 小范围验证跑通 / 教会对方 / 达成共识 / 规则升级）→ 立场锚回收 → 末镜点题字幕 |

### 3.3 反转规则

- 全片 **2–3 次反转**，必须来自**真实职场逻辑**：决策冲突、信息差、他人选择、数据证明、被质疑后的验证；**禁止**巧合、事故（如「全城掉线」是事故报告不是故事）、超能力、天降救援。
- 每次反转在文本稿里写成一行表：`位置｜观众预期｜实际发生｜逻辑来源`。
- 反转 3 的落点优先是「**把事做周全 / 升级成规则或方法 / 让对方自己成长**」，而不是「老板破例通融」——破例是人情，沉淀成规则、方法或能力才是制度。

### 3.4 情绪曲线与色调

- 沿用 `角色圣经.md` 第六节色调映射：日常（室内明亮 + 窗外雨，蓝橙平衡）→ 回忆 / 初心（暖光百叶窗）→ 诱惑 / 压抑（金光 / 低饱和）→ 冲突（大雨冷调）→ 危机想象（冷色浓雾）→ 收尾（温暖大气、万家灯火）。
- 首镜给情境，末镜收束点题；末镜可上一句价值观点题字幕（≤20 字，对偶或对仗），写入 `ending_subtitle` 或末镜 `narration`。

## 3A. 导演工艺（固定机位图生视频产线，逐条落实到每镜）

> 本产线是**固定机位、帧内微动**的图生视频，不做推拉摇移；导演手段全部压进「景别切换、帧内小动作、光线、声音、留白」。每镜文本稿都要写清本节对应的项。

### 3A.1 开场三秒钩子

- 第 1 镜前 3 秒必须出现一个**信息事件**：红色告警在大屏炸开、一句立场先声夺人、一个异常声响（门被推开 / 提示音密集 / 数据跳动）。
- 禁止用空镜听雨、空城市、缓慢推近开场；旁白可在第 1–2 句进入，不拖到第 2 镜之后。

### 3A.2 景别序列（用景别切换代替运镜）

| 景别 | 承担职责 | 典型镜位 |
|---|---|---|
| 远景 / 全景 | 立情境：运营中心、雨夜城市、会议室、万家灯火 | 镜 1 建立、末镜回收 |
| 中景 | 对手戏：立场、决策、讨论、带教 | 镜 2、3、7、10 |
| 近景 / 特写 | 反应与关键动作：手悬在按钮上、记录变灰 / 点亮、推回、落笔、眼眶红、数据落定 | 镜 4、5、8、9、11 |

- 避免连续 3 镜同一景别、同一机位；每 3–4 镜至少一次景别变化。
- 特写只给**关键动作和反应**（按下、落笔、推回、点亮、眼眶红），不给无意义的物件大特写。

### 3A.3 帧内表演节拍（情绪压进小动作，禁止夸张）

图生视频只允许微动，把情绪写进可生成的小动作（按本集角色选用，不全用）：

- **TT虎**：动作前爪子悬停一拍、抿嘴、视线在两个选项之间往返、完成后肩背沉一下；被拒时身体不退但耳朵 / 肩膀收紧；递出东西先放平再轻推；自学时盯屏眨眼、记一笔。
- **猫老板**：推门带风、通知 / 文件轻拍桌面、推东西动作轻飘带点得意；被说服时靠回椅背沉默一拍，再起身走向白板。
- **同事 / 对方角色**：手停在键盘、扶一下耳麦、深吸一口气、眼眶红了扭过头、低头记笔记。
- 禁止夸张表情、大幅度跑动、多余肢体、挥手比划；所有情绪靠「停一拍 + 一个小动作」完成。

### 3A.4 切镜锚点（不靠特效转场）

- **动作中切**：手悬停 → 按下；伸手 → 被按住。
- **视线切**：看屏幕 → 转头看对方；看记录 → 抬头看老板 / 同事。
- **声音桥**：门响、按键音、耳麦提示音、翻页声把下一镜带出来。
- **位置 / 形状匹配**：一条记录被拖出 → 它重新点亮；白板旧字下方添一行新字。
- 每镜在文本稿写明：从哪个锚点切入、切后新增什么信息。

### 3A.5 光影冷暖节点（写进 image_prompt）

- B1 室内明亮 + 窗外雨，蓝橙平衡；B2 压力落下整体偏冷；B3 关键选择时屏幕红光 / 金光映脸；
- B4 深化时一盏灯转暖；B5 被拒冷调，用事实证明时绿光 / 暖光渐入；B6 兑现暖金铺满，末镜万家灯火。
- 每镜写明主光方向与冷暖倾向，不让模型自由发挥色温。

### 3A.6 声音四层与 BGM 情绪曲线

每镜 `sound` 分四层写清，不要只写「紧张音乐」：

1. **环境层**：暴雨拍窗 / 服务器风扇 / 城市低鸣 / 键盘声 / 会议室低语；
2. **动作拟音层**：按键、纸张拍桌、推门、耳麦提示、翻页、落笔；
3. **BGM 层**：轻起 → 绷紧（低弦 / 心跳感）→ 反转点收轻留白 → 温暖展开 → 末镜收一个和弦；
4. **旁白层**：旁白进入时 BGM 主动让音量。
- 反转落点配乐收轻，**留 1 拍无旁白空白**，让反应落地。

### 3A.7 节奏留白与末镜停留

- 每次反转后给 1–2 秒无旁白留白（只留环境 + BGM），不把台词塞满每一秒。
- 末镜稳定停留 ≥2 秒再结束，点题字幕淡入后停稳，不淡黑、不加新动作。

### 3A.8 一个可复述视觉母题

- 每集设计一个观众看完能复述的视觉符号，并首尾呼应（示例：EP.02 名单一条条变灰 → 白名单重新点亮；每集自定，不照搬）。
- 母题在 logline 阶段就定，贯穿 B3 与 B6。

## 4. 逻辑护栏（动作白名单 / 黑名单，逐条必守）

### 4.1 主角允许做的真实动作（白名单，按本集命题选用）

- **执行类**：按制度 / 既定流程执行决策、检查、排查；
- **核对类**：查数据、对台账、看大屏、复盘记录、小范围验证；
- **建议类**：在规则内提出补漏、改善、新想法、可验收目标；
- **协助类**：帮同事补位、带教（教会对方自己做，不替他做完）、平等讨论；
- **结果类**：展示系统自动完成的结果、交付验收后的成果、升级后的规则 / 方法。

### 4.2 禁止动作（黑名单，出现即废稿）

1. **零越权代劳**：不手动操作应由系统 / 专业岗位完成的事（手动派单、替司机开车、替客服对外承诺、替上级拍板、替同事把活做完）。
2. **主角不下场代替专业角色**：不开车接单、不弃车、不递伞、不亲自送客。
3. **转折不靠外部事故 / 巧合 / 天降救援**（如「全城掉线」「客户刚好来电」）。
4. **不靠乘客苦等、换平台、对外服务态度制造冲突**；矛盾一律来自公司侧（决策、难题、诱惑、分歧、缺口）。
5. **不出现自相矛盾的处理**（如同一单既取消又送达；若必须写两阶段，分属两次系统动作并交代清楚）。
6. **旁白只描述画面真实存在的动作**；做不到的动作砍掉，或用姿态 / 拒绝承担。
7. 数字写中文（「一百三十七单」「八十一岁」），不写英文缩写（Robotaxi / IPO / KPI 等 TTS 会读崩）；不出现人类、不出现新常驻角色、屏幕不生成可读文字（`no readable text, no letters`）。

## 5. 两步走工作流与单集专属信息

### 5.1 两步走

1. **文本稿（先审，不落 JSON）**：logline + 立场锚 + 反转表 + 12–13（或 18–24）镜文字表，每镜写清：景别、画面（帧内小动作 / 场景 / 主光冷暖）、声音（环境 / 拟音 / BGM / 旁白四层）、旁白（含角色对白）、切镜锚点。
2. **落 scenes[]（审过再落库）**：按第 6 节 schema 写 `image_prompt` / `video_prompt`，每镜带视觉 DNA 前缀，校验时长合计（≥120s）与旁白密度。

### 5.2 单集任务提示词必须携带的专属信息（母版不给）

规范母版只管通用规则；每集任务提示词必须另写清：

1. 本集集数、关键词与《系列总览》对内定义原文；
2. 一句话命题 logline 与立场锚（台词或动作）；
3. 本集对方 / 压力源是谁（猫老板 / 兔妈妈 / 一次性同事 / 难题），出场角色分配；
4. 本集钩子与场景（取自 `选题库.md`）；
5. 本集 2–3 次反转的「预期 / 实际 / 逻辑来源」；
6. 本集视觉母题与光影走向；
7. 本集点题字幕。

## 6. 场景 schema（project.json 的 `scenes[]`，year/age 留空）

```json
{
  "index": 1,
  "year": "",
  "age": "",
  "title": "第1镜 · （本集短标题）",
  "duration": 12,
  "narration": "（本集旁白，30–45 字，含角色对白用「」包裹）",
  "sound": "环境：…；拟音：…；BGM：…；旁白…",
  "image_prompt": "<视觉DNA前缀> + 景别 + 本镜画面主体 / 帧内动作 / 主光方向与冷暖；出场角色按《角色圣经》重复英文核心句",
  "video_prompt": "Locked-off static camera, absolutely no camera movement, no zoom, no pan. Keep all characters fully inside the frame, no morphing, no extra limbs. Subtle in-frame motion only: …（本镜帧内微动）",
  "image_path": "",
  "video_path": "",
  "audio_path": "",
  "image_status": "pending",
  "video_status": "pending"
}
```

### 字段合同

| 字段 | 要求 |
|---|---|
| `index` | 从 1 连续编号，不跳号 |
| `year` / `age` | **一律留空字符串**（虚构 IP 无年份年龄；`set-script` 会保留这两个空字段，不要删键） |
| `title` | `第N镜 · 短标题`，10 字内 |
| `duration` | 整数秒；A 档 10–13s / B 档 5–7s；**合计 120–180s，不得 <120s** |
| `narration` | 每镜 30–45 字、语速 ≤4.3 字/秒；角色对白直接写进本段旁白，用「」包裹（schema 无独立对白字段）；只写画面真实存在的动作 |
| `sound` | 按环境 / 拟音 / BGM / 旁白四层写，一行逗号分隔 |
| `image_prompt` | 先贴 `分镜模板.md` 第三节视觉 DNA 前缀，再写景别、帧内动作、主体 / 环境 / 主光冷暖；出场角色的英文核心句按《角色圣经》原样重复 |
| `video_prompt` | 以 `Locked-off static camera, absolutely no camera movement, no zoom, no pan` 开头，再写帧内微动与一致性约束（`fully inside the frame, no morphing, no extra limbs`） |

### 落库方式（注意 `set-script` 的坑）

- **推荐：直接编辑 `projects/<项目>/project.json` 的 `scenes`**，可完整保留 `duration` / `sound`。
- 若用命令：`<PY> studio.py set-script <project_id> -f script.json`，**该命令重建 scenes 时会丢弃 `duration` 和 `sound`**，落库后必须补回这两个字段；随后把 pending 的 script 任务标记 done。
- 两种方式都要保证：`aspect: landscape`、`category: dingding-city`、`series: 叮叮城故事`，末镜点题句写入 `ending_subtitle`。

## 7. 剧本自检清单（开集必过，逐条勾选后再交付）

**主题与角色**
- [ ] 角色只用确认班底 + 本集一次性动物 / 无名客串，**无新造常驻角色、无人类**
- [ ] 主题落在本集关键词的对内定义，通过 2.2 跑题三问，**非对外服务态度**
- [ ] 含「对方 / 压力源」与「公司侧既定对象」两个必备支点

**结构与反转**
- [ ] 有 logline、立场锚，且立场锚在末镜回收
- [ ] 含 2–3 次反转，每次反转有「预期 / 实际 / 逻辑来源」，且来自真实职场逻辑（非巧合 / 事故）
- [ ] 决策 / 结果落点是「补周全 / 升级规则方法 / 对方自己成长」，不是「老板破例」

**导演工艺**
- [ ] 第 1 镜前 3 秒有信息事件（钩子），无空镜慢起
- [ ] 景别有全景 / 中景 / 特写序列，无连续 3 镜同景别同机位
- [ ] 每镜情绪压进帧内小动作，无夸张表演 / 多余肢体
- [ ] 每镜写明切镜锚点；反转后有 1–2 秒留白；末镜稳定停留 ≥2 秒
- [ ] 光影冷暖随六拍推进；BGM 走完「轻起→绷紧→留白→展开→收和弦」
- [ ] 有一个首尾呼应的可复述视觉母题

**逻辑护栏**
- [ ] TT虎 未开车 / 未越权代劳（未手动派单、未替人做完、未替上级拍板）/ 未递伞送客
- [ ] 无外部事故巧合式转折；无乘客苦等换平台式冲突；无自相矛盾的处理
- [ ] 旁白只描述画面真实存在的动作；数字写中文、无英文缩写

**工程与声音**
- [ ] 每镜 `image_prompt` / `video_prompt` 带视觉 DNA 前缀，`video_prompt` 以静态机位句开头
- [ ] `scenes[]` 的 `year` / `age` 留空，含 `sound` 字段（四层）
- [ ] **`duration` 合计 120–180 秒（≥2 分钟）**，画幅 `landscape`；旁白 ≤4.3 字/秒
- [ ] 角色外观与《角色圣经》一致（毛色 / 王字纹 / 脸颊每侧 2 条「>」虎纹 / 蓝工装工牌）
