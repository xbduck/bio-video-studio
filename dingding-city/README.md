# 叮叮城故事 · 企业文化专栏

> 系列中文名：**叮叮城故事**
> 主角：**TT虎**（虚构 IP 形象，无真实年份 / 年龄）
> 城市：**叮叮城**
> 载体：3D 卡通电影感横屏短片（16:9，图生视频产线）

---

## 一、栏目定位

「叮叮城故事」是 T3 出行**企业文化 / 内训 / 合规宣导**的 IP 短剧系列，用固定主角 **TT虎** 讲每集一个价值观命题。

它和仓库里另外两条产线**不是一回事**，别混：

| 产线 | 驱动方式 | 代表作 |
|------|----------|--------|
| `projects/` 生平短片 / 企业文化 | 真实人物或企业的**编年史**（`year` / `age` 时间轴） | `projects/T3出行`（公司史）、`projects/朱元璋` |
| `series/` 听书 | 多集长音频（`paragraphs` → TTS → 幻灯片） | `series/ming-emperors` |
| **叮叮城故事（本栏）** | **虚构 IP 情景短剧**，按「每集一个价值观命题」驱动，**无年份年龄** | EP.01 坚守底线 |

> 关键差异：**TT虎 是虚构角色，没有生卒年、没有年龄**。所以本栏的分镜模板**砍掉了 `year` / `age` 字段**，其余直接复用 `projects/<项目>/project.json` 的 `scenes[]` schema（`narration` / `image_prompt` / `video_prompt`），生成仍走 `projects/` 图生视频产线（见下文）。

## 三、目录约定

```
bio-video-studio/
├─ dingding-city/                ← 本栏（IP 资产层，不跑引擎）
│  ├─ README.md                  ← 你正在看的文件
│  ├─ 角色圣经.md                ← TT虎/猫老板/小助手 锁死规范 + 视觉体系 + 一致性红线
│  ├─ 分镜模板.md                ← 单集分镜标准字段 + project.json schema + 视觉DNA prompt
│  ├─ 系列总览.md                ← 价值观表 9 个行为关键词 → EP.01–09 权威总表
│  ├─ 选题库.md                  ← 每集剧情钩子与可复用场景
│  └─ ep01_坚守底线/             ← EP.01 权威 12 镜脚本 + 本集说明
└─ projects/                     ← 实际生成层（每集一条）
   ├─ 叮叮城故事EP.01_坚守底线/   ← 12 分镜（完整脚本）
   └─ 叮叮城故事EP.02_说到做到/ … EP.09_共创共赢/  ← 骨架（1 分镜，待写）
```

**原则**：IP 圣经 / 模板 / 选题 只在本栏维护一份；每集的成片素材仍落在 `projects/<项目>/`，生成流程、成本、必踩的坑全部沿用 `README.md` 第十一节（IP 角色动画短片）。
