## 二、角色班底（只准用这些，禁止新增常驻角色）

- **TT虎**：运营中心夜班值守，盯运力大盘、执行团队决策、在规则内补漏；**永远不出车接单、不开车、不递伞**。外观以《角色圣经》为准（橙黄金虎皮、深棕虎纹、额头黑「王」字纹、白口鼻区白肚皮、黑圆眼、粉鼻头、蓝内耳、蓝工装 + 工牌、脸颊每侧 2 条「>」形虎纹、头大身圆 Q 版）。
- **猫老板**：城市运营负责人，灰毛 / 圆眼镜 / 灰西装；本集下达「批量取消」的**正确团队决策**，不是反派；后期把补漏升级为新规则。
- **小助手**：飘浮平板机器人，仅在提醒 / 显影数据时出场，投红 / 绿光，不抢戏。
- **兔妈妈**：客服坐席，本集承诺对象与协同的另一头（**替换旧稿里被禁的「小鹿」，禁止再出现小鹿 / 鹿角色**）。
- **客串乘客**：一位独居老年动物乘客（泛指，不命名、不立人设、不给小传；旧稿「兔奶奶」改为无名老年动物），只承担「这件事为什么重要」的由头。
- **铁律：全城只有动物，没有人类**；`NO human hands`，不出现人类乘客 / 人类客服。

## 三、主题落点（对内，禁止写成对外服务态度）

逐字对齐《系列总览》EP.02 对内定义：**言出必行，行必果；在团队合作和部门协同中站在对方角度思考问题，从言行上完全支持团队决策。**

冲突必须发生在「运营值守 ↔ 客服同事」「个人承诺 ↔ 团队决策」之间；禁止写成老人等车陪伴、对外服务态度、乘客投诉安抚。通过规范 v2.1 第 2.2 节跑题三问。

## 四、剧情骨架（以 v6 为起点，按护栏校正）

1. 暴雨夜运力告急，猫老板下达正确决策：未接单超十五分钟的单全部批量取消、统一发券安抚（保安全、保大盘，这是决定不是商量）。
2. **承诺锚（第 2 镜落下）**：TT虎 刚答应兔妈妈「我帮你盯着」她那单独居老年乘客的工单。
3. **反转 1（第 4 镜）**：观众以为他会偷偷保下那一单；他没有阳奉阴违，先一条不落地执行完整批取消（名单变灰）——从言行上完全支持团队决策。
4. **反转 2（第 5–6 镜）**：兔妈妈要自己去道歉担责，TT虎 不让她扛；他换到对方角度，从灰记录里看见决策对特殊乘客是盲区。
5. **规则内争取（第 7–9 镜）**：他先报「决策我执行完了」，再用数据（独居老年乘客在取消名单中的数量、系统可查的年龄 / 地址 / 无障碍标记）向老板提出补「特殊乘客白名单」；被拒后不退让，用事实再证明，全程不越权、不拍桌。
6. **反转 3（第 10 镜）**：不是老板破例通融，而是把白名单补成一条全城推行的新规则——让团队决策更周全。
7. **兑现（第 11 镜）**：系统自动派单 / 自动保障把那一单送达，**无手动塞单、无打电话找司机**；兔妈妈红了眼眶。
8. **末镜（第 12 镜）**：台账记录 + 点题字幕「说到做到——答应了，就办到；支持团队，也让团队更周全」，承诺锚回收。

## 五、导演工艺（按规范 v2.1 第 3A 节落实到每镜）

- **开场钩子**：第 1 镜前 3 秒出现信息事件（红色告警在大屏炸开 / 暴雨声先入 / 承诺句先声夺人），禁止空镜听雨慢起。
- **景别序列**：镜 1 全景立情境（雨夜运营中心）→ 镜 2/3 中景对手戏（承诺、决策）→ 镜 4/5/8/9 近景特写（手悬停在按钮上、名单变灰、被拒、数据说服）→ 镜 12 全景回收（灯火 / 台账）；不连续 3 镜同景别同机位。
- **帧内小动作**：TT虎 按键前爪子悬停一拍、视线在承诺单与决策键之间往返、按下后肩背沉一下、被拒时身体不退耳朵收紧；猫老板通知轻拍桌面、被说服时靠回椅背沉默一拍再走向白板；兔妈妈手停在键盘、扶耳麦、眼眶红扭过头。禁止夸张表情与大幅动作。
- **切镜锚点**：动作中切（悬停→按下）、视线切（看屏幕→看对方）、声音桥（推门 / 按键音）、位置匹配（灰记录拖出→白名单点亮）。
- **光影冷暖**：B1 室内明亮蓝橙平衡 → B2 决策落下偏冷 → B3 红光映脸 → B4 一盏灯转暖 → B5 被拒冷、数据说服绿光 / 暖光渐入 → B6 暖金铺满、万家灯火；每镜写进 image_prompt。
- **声音四层**：每镜 sound 写明环境（暴雨 / 风扇 / 键盘）、拟音（按键 / 拍桌 / 推门 / 耳麦提示）、BGM（轻起→绷紧→反转点留白一拍→温暖展开→末镜收和弦）、旁白；旁白进入时 BGM 让路。
- **留白**：三次反转后各留 1–2 秒无旁白空白；末镜稳定停留 ≥2 秒，点题字幕淡入停稳。
- **视觉母题**：名单一条条变灰 → 白名单重新点亮（首尾呼应）。

## 六、结构与声音要求

- 12 镜抒情档，六拍配比见规范 v2.1 第 3.2 节；2–3 次反转，每次在文本稿里写清「位置｜观众预期｜实际发生｜逻辑来源」。
- 旁白每镜 30–45 字、≤4.3 字/秒，角色对白直接写进本段旁白用「」包裹；数字写中文（一百三十七单、八十一岁），禁英文缩写（Robotaxi / KPI / IPO 等）。
- `video_prompt` 每镜以 `Locked-off static camera, absolutely no camera movement, no zoom, no pan` 开头，只写帧内微动。

## 七、逻辑护栏（逐条必守，违反即废稿）

- 零手动派单 / 转单 / 打电话协调司机；TT虎 不开车、不弃车、不递伞、不亲自送客。
- 不出现「同一单既取消又送达」；先取消，再由白名单 / 新规则让系统重新保障（分属两次系统动作）。
- 不靠乘客苦等、换平台制造冲突；矛盾来自公司侧主动动作。
- 旁白只描述画面真实存在的动作；屏幕 `no readable text, no letters`，不生成可读招牌 / 小字。
- 角色只用第二节班底，不新造常驻角色，不出现人类。

## 八、落库方式

- 把 12 镜写入 `projects/叮叮城故事EP.02_说到做到/project.json` 的 `scenes[]`，字段：`index / title / duration / narration / sound / image_prompt / video_prompt / image_path / video_path / audio_path / image_status / video_status`；`year` / `age` 留空字符串；`aspect: landscape`，`category: dingding-city`，`series: 叮叮城故事`，点题句写入 `ending_subtitle`。
- 每镜 `image_prompt` 先贴《分镜模板》第三节视觉 DNA 前缀，出场角色英文核心句按《角色圣经》重复。
- **推荐直接编辑 project.json**（`studio.py set-script` 会丢弃 `duration` / `sound`，若用命令落库必须补回）；完成后把 pending 的 script 任务标记 done。

## 九、交付时必须附上

1. 一句话命题 logline；
2. 三次反转表（位置｜观众预期｜实际发生｜逻辑来源）；
3. **12 镜时长合计（秒，必须 ≥120 秒）** 与每镜字数 / 语速（≤4.3 字/秒）；
4. 规范 v2.1 第七节自检清单逐条勾选结果（含导演工艺项：开场钩子 / 景别序列 / 帧内小动作 / 切镜锚点 / 光影冷暖 / 声音四层 / 留白 / 视觉母题）；
5. 全文不得出现「小鹿」「人类」「手动派单」「开车接单」。
