# 分镜模板 · 叮叮城故事（单集）

> 用法：复制本文件（或下面的 `project.json` schema）开新一集。
> 与 `projects/<项目>/project.json` 的 `scenes[]` **完全兼容**，唯一区别是**去掉了 `year` / `age`**——
> 因为 TT虎 是虚构 IP，没有年份 / 年龄，硬填反而误导。

---

## 一、单集分镜标准字段（写给人看的表）

每一镜建议包含以下字段，顺序固定，便于校对：

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| 镜号 | 第 N 镜 | 必填 |
| 时长 | 秒（8–14s，成片 1–3 分钟） | 必填 |
| 比例 | 固定 16:9 横屏 | 必填 |
| 画面 | 镜头语言 + 主体动作 + 场景 | 必填 |
| 声音 | 环境音效 + BGM 情绪 | 必填 |
| 旁白 | 一句中文旁白（25–32 字/句，约 4.3 字/秒） | 有则填 |
| 一致性 | 默认「见角色圣经」，特殊镜注明 | 选填 |
| 生成参数 | 模型 / 特殊约束（如第 5 镜 Seedance 2.0 Mini） | 选填 |

**示例（EP.01 第 1 镜）：**
```
第 1 镜 | 8s | 16:9
画面：白色小车驶入城市配送中心 → 镜头跟随 TT虎 下车进入大厅 → 屏幕弹出大量订单提示 → TT虎 迅速接单
声音：雨声渐弱、电子提示音、订单弹出音效、节奏开始加快
旁白：（无）
一致性：见《角色圣经》TT虎
```

## 二、可直接复制的 `project.json` 场景 schema

新建 `projects/<项目>/project.json` 时，按这个结构填（**无 year/age**）：

```json
{
  "slug": "叮叮城故事EP.01_坚守底线",
  "person": "TT虎",
  "title": "叮叮城故事·EP.01 坚守底线",
  "summary": "TT虎 作为叮叮城运营管家，面对业绩诱惑与六张临期证件，最终守住底线。",
  "style": "3D cartoon cinematic, chibi Q-version tiger TT-Hu, orange-gold fur, blue work uniform, rainy-night city of Dingding, neon blue-orange, Pixar-like 3D render, 35mm anamorphic, soft global illumination, no readable text, no letters",
  "voice": "MiniMax speech-2.5-hd-preview / audiobook_male_1",
  "rate": "0.98",
  "bgm_path": "",
  "bgm_volume": 0.18,
  "scenes": [
    {
      "index": 1,
      "title": "第1镜 · 驶入配送中心",
      "duration": 8,
      "narration": "",
      "sound": "雨声渐弱、电子提示音、订单弹出音效、节奏开始加快",
      "image_prompt": "3D cartoon, TT-Hu orange-gold tiger in blue work uniform driving a white delivery car into a rainy-night city distribution center, neon blue-orange, cinematic, no readable text",
      "video_prompt": "Locked-off static camera, absolutely no camera movement, no zoom; the white car drives in, TT-Hu steps out, screens pop up with order alerts, keep character consistent, fully inside frame, no morphing",
      "image_path": "images/01.png",
      "video_path": "videos/01.mp4",
      "audio_path": "audio/01.mp3",
      "image_status": "pending",
      "video_status": "pending"
    }
  ]
}
```

> 字段对照：`duration` 是新增（企业文化短片按秒对齐）；`sound` 是新增（环境音效层，见 README 十一节「整体像播报、没电影感」坑）；`narration` / `image_prompt` / `video_prompt` 与既有 `projects/` 完全一致。

## 三、叮叮城 3D 卡通视觉 DNA（每镜 prompt 前缀）

出图 / 出视频的 prompt **都先贴这段**，再补本镜具体内容，保证全系列统一画风：

```
3D cartoon cinematic style, chibi Q-version tiger character TT-Hu with orange-gold fur,
dark brown/black stripes, exactly two dark brown stripes on each cheek forming a ">" shape
beside the outer corner of each eye (no other cheek stripes),
clear black "王" mark on forehead, white muzzle and belly,
blue inner ears, big round black eyes, pink nose, short round limbs, blue work uniform
with ID badge, Pixar-like 3D render, soft global illumination, 35mm anamorphic lens,
cinematic lighting, rainy-night city of Dingding, neon blue-orange contrast,
no readable text, no letters, keep character perfectly consistent, fully inside frame,
no morphing, NO human hands, NO tail visible, nobody else enters
```

**图生视频额外必须加（防猛推镜）：**
```
Locked-off static camera, absolutely no camera movement, no zoom
```

## 四、单集交付清单（开集自查）

- [ ] `projects/<项目>/project.json` 用上方 schema，已去掉 year/age
- [ ] 每镜 `image_prompt` / `video_prompt` 都带「视觉 DNA 前缀」
- [ ] 角色特征与 `角色圣经.md` 一致（毛色/脸型/工装/工牌/王字纹/**脸颊每侧 2 条「>」形虎纹**）
- [ ] 旁白只描述画面真实存在的动作/物体
- [ ] 时长合计落在 1–3 分钟（约 18–24 镜 × 5–7s，或 12 镜 × 8–14s）
